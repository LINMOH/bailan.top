## 项目结构

本项目为静态网页，无需后端支持，适合部署在：

- GitHub Pages
- Cloudflare Pages
- Vercel / Netlify

目录结构如下：

```

.
├── index.html
├── style.css
├── script.js
└── assets/

```

---

## 快速部署

### GitHub Pages

1. Fork 本仓库
2. 设置 ➜ Pages ➜ 分支选择 `main` ➜ `/ (root)`
3. 保存后访问：`https://你的用户名.github.io/bailan.top`
